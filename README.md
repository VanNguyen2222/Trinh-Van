# Thiệp Cưới Online - Seoul Ivory Style (Cập nhật mới nhất)

Website Thiệp Cưới Online xây dựng bằng Next.js 14, Tailwind CSS và TypeScript.

## 🌟 Các Tính Năng Mới Đã Được Cập Nhật:
1. **Khắc phục khoảng trắng trang bìa**: Trang bìa thiết kế `fixed inset-0` trượt mở mượt mà không bị hở phông nền trắng.
2. **Section Lời Mời & Calligraphy Font**: Thêm font `Great Vibes` chữ uốn lượn sắc nét cho tên Chú Rể & Cô Dâu kèm họa tiết SVG chuẩn mẫu.
3. **Mời Từng Người (Cá Nhân Hóa Tên Khách Mời)**: Tự động nhận tham số tên khách từ URL (Ví dụ: `https://your-domain.com/?to=Anh+Tuan` -> Hiện "TRÂN TRỌNG KÍNH MỜI ANH TUẤN TỚI DỰ").

## 🚀 Hướng Dẫn Khởi Chạy (Local)

1. Giải nén file zip này.
2. Mở Terminal tại thư mục gốc dự án và chạy:
   ```bash
   npm install
   ```
3. Khởi chạy server phát triển:
   ```bash
   npm run dev
   ```
4. Truy cập `http://localhost:3000` hoặc thử đường dẫn gửi riêng cho khách: `http://localhost:3000/?to=Anh+Tuan`
